# Word pdf

Ejemplo real de ST. Revisa `src/main.st` y los permisos de `PyForge.toml`.

Desde ESTA carpeta, con PyForge actualizado instalado:

```bash
pyforge run
```

En Windows utiliza la terminal de WSL. El auxiliar opcional necesita Python 3.11 o posterior.
Los destinos de archivos deben ser nuevos: trabaja en una copia temporal del ejemplo.
No vuelvas a ejecutarlo sobre documentos que quieras conservar.

Consulta [integraciones](../../../docs/INTEGRACIONES.md) para dependencias y limitaciones.
